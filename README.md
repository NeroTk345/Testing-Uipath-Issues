# Testing-Uipath-Issues

Feedback and questions for the DattoRMM and NOC tooling.

## How to report something

1. Go to **Issues** and click **New issue**.
2. Pick the template that fits: **Bug**, **Question** or **Idea**.
3. Fill in the form. Pick the product (DattoRMM or NOC).

## Rules

- Never post tokens, API keys or customer names.
- Paste log lines or screenshots where they help.
- One issue per problem, so it can be tracked.
